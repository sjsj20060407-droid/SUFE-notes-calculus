# 教学大纲逐节覆盖对照

依据提供的 2026 秋教学大纲第 4—6 页。基础单元与共享概念可从多个章节进入，进度不会重复计数。

## 第 1 章 高维数据简介，散点图与回归

能说清样本、变量和高维问题；用散点与条件均值判断模型是否合适。

- 第 1 节 高维数据简介 → 高维是什么：样本数与特征数的关系
- 第 2 节 回归的基本概念 → 回归：预测的是平均响应
- 第 3 节 散点图 → 散点图：先看形状，再选模型
- 第 4 节 均值与方差函数 → 回归：预测的是平均响应；离散程度：为什么要平方

实践任务：从一个身边问题写出响应、特征与预测时刻，画示意散点，提出两个不能直接做回归的风险。

## 第 2 章 简单线性回归

能从误差平方和推出估计，算 SE、t、区间、预测和 R²，并说明条件。

- 第 1 节 简单线性回归模型 → 回归：预测的是平均响应
- 第 2 节 最小二乘估计 → 最小二乘：让一条线尽量靠近所有点；残差与正交：为什么交叉项消失；极大似然：什么参数让数据最说得通
- 第 3 节 参数估计的性质 → 无偏与方差：正确方向不等于稳定；标准误：系数究竟估得有多准
- 第 4 节 区间估计 → 置信区间：估计值加减误差余量
- 第 5 节 假设检验 → t 检验：与假设值差了几个标准误
- 第 6 节 预测 → 预测：平均值与下一个个体不同
- 第 7 节 可决系数 → R²：解释了多少样本变化

实践任务：用 5 个自己编的观测手算一条回归线，再在 R 中复现；解释差异而不是只交系数。

## 第 3 章 多元线性回归

能读设计矩阵，计算对比与预测的方差，解释中心化、共线性和联合检验。

- 第 1 节 多元线性回归模型 → 多元回归：控制其他变量以后
- 第 2 节 最小二乘估计 → 多元回归：控制其他变量以后；残差与正交：为什么交叉项消失
- 第 3 节 参数估计的性质 → 多元回归：控制其他变量以后；无偏与方差：正确方向不等于稳定；共线性：两个变量的信息重叠了；异方差与加权：更准的数据权重大
- 第 4 节 区间估计 → 线性组合：一条公式解决很多问题；多元回归推断：从一条线到一个线性组合；置信区间：估计值加减误差余量
- 第 5 节 假设检验 → 线性组合：一条公式解决很多问题；t 检验：与假设值差了几个标准误
- 第 6 节 预测 → 多元回归推断：从一条线到一个线性组合
- 第 7 节 可决系数 → R²：解释了多少样本变化；多元回归推断：从一条线到一个线性组合
- 第 8 节 中心化 → 中心化：换原点，不换信息
- 第 9 节 F-检验 → 联合 F 检验：多项限制一起检查

实践任务：比较含/不含一个高度相关变量的模型，记录系数 SE 与预测如何变化。

## 第 4 章 复杂自变量

能把类别与非线性特征变成设计矩阵，知道何时用多项式、样条或 PCA。

- 第 1 节 分类变量 → 分类变量：用 0 和 1 表示组别
- 第 2 节 多项式回归 → 多项式回归：曲线也可以线性于参数
- 第 3 节 样条函数 → 样条：把曲线分段接起来
- 第 4 节 主成分分析 → 主成分分析（PCA）：换方向，再保留少数方向；特征向量与 SVD：理解降维的数学底座

实践任务：对同一组弯曲数据拟合直线、多项式与样条，保留独立验证点，说明为何选择某个复杂度。

## 第 5 章 变量选择、非线性回归

能解释复杂度与泛化，比较准则和 CV，认识逐步选择与非线性拟合限制。

- 第 1 节 Bias-variance tradeoff → 偏差—方差分解：为什么更灵活不总更好；过拟合：训练好不代表新数据好
- 第 2 节 模型选择准则 → 模型选择准则：AIC、BIC 和交叉验证
- 第 3 节 逐步回归 → 逐步回归与高维贪心选择
- 章标题补充：非线性回归 → 非线性回归单元

实践任务：写出训练—调参—最终测试三个阶段，列出数据泄漏可能发生的每一步。

## 第 6 章 正则化方法、高维回归分析

能区分预测与变量恢复，用 Ridge/Lasso，手算一次更新，设计无泄漏评估。

- 第 1 节 正则化方法 → Ridge 正则化：用收缩换稳定；Lasso 与 Elastic Net：为什么有的系数变成零
- 第 2 节 高维变量选择的方法分类 → 高维变量选择：先分清你要预测还是找变量
- 第 3 节 高维逐步选变量法 → 逐步回归与高维贪心选择
- 第 4 节 高维正则化方法 → Lasso 与 Elastic Net：为什么有的系数变成零；Ridge 正则化：用收缩换稳定
- 第 5 节 算法选讲 → 正则化算法：坐标下降和近端更新；梯度与迭代：没有闭式解时怎么学参数
- 第 6 节 理论性质简介 → 高维理论：哪些条件让“少样本多变量”可学
- 第 7 节 实际数据案例 → 实际数据案例：让每一步都能被检查

实践任务：模拟 100 个样本、200 个特征、5 个信号，比较 Ridge 和 Lasso 的预测误差与支持稳定性。

## 第 7 章 logistic 回归与广义线性模型

能从 η 转回概率或均值，解释链接、损失与正则化，识别完全分离。

- 第 1 节 logistic 回归 → Logistic 回归：从线性分数到概率；正则化分类：从概率损失到稳定决策
- 第 2 节 广义线性模型 → 广义线性模型：响应、线性预测子、链接函数
- 第 3 节 正则化方法 → 正则化分类：从概率损失到稳定决策

实践任务：在二分类小数据上比较概率与阈值决策；把阈值改变造成的成本写成一张表。

## 第 8 章 分类问题选讲

能比较分类模型的分布假设，算混淆矩阵指标，考虑不平衡与高维风险。

- 第 1 节 LDA 简介 → LDA 分类：先为每一类建分布
- 第 2 节 QDA 简介 → QDA：允许类别拥有不同的散布
- 第 3 节 Fisher LDA 简介 → Fisher LDA：找一个最能分开类别的方向
- 第 4 节 朴素贝叶斯 → 朴素贝叶斯：条件独立如何简化高维分类
- 第 5 节 分类方法评价标准、集成方法 → 分类评价：少数类不能被准确率藏起来；集成方法：多个模型为什么能互补
- 第 6 节 高维分类方法简介 → 高维分类：先限制有效复杂度

实践任务：在不平衡分类问题上同时报告 accuracy、precision、recall，解释为何首选某个指标。

## 第 9 章 降维方法介绍

能区分保方差、分类型、保距离和保邻居的目标，避免误读二维可视化。

- 第 1 节 主成分分析 → 主成分分析（PCA）：换方向，再保留少数方向；特征向量与 SVD：理解降维的数学底座
- 第 2 节 因子分析 → 因子分析：用潜在原因解释相关性
- 第 3 节 Fisher LDA → Fisher LDA：找一个最能分开类别的方向
- 第 4 节 Kernel PCA → Kernel PCA：用相似度做非线性投影
- 第 5 节 Multidimensional Scaling (MDS) → MDS：从距离恢复坐标
- 第 6 节 Stochastic Neighbor Embedding (SNE) → SNE 与 t-SNE：邻居图不能当精确地图

实践任务：同一数据对照 PCA 和 t-SNE；记录缩放、随机种子、邻域参数，写出图支持和不支持的结论。

## 第 10 章 Embedding 与谱方法

能解释嵌入保存的关系，构造小图拉普拉斯并说明谱坐标的意义。

- 第 1 节 Embedding → Embedding：一个向量究竟保留什么
- 第 2 节 谱方法 → 谱方法：把图的连接变成坐标

实践任务：画一个 6 节点图，算度数与 L，再比较加一条跨群边前后的结构直觉。

## 第 11 章 矩阵低秩结构的探索

能计算低秩近似误差，理解网络与推荐中缺失、依赖和评估的区别。

- 第 1 节 网络数据分析 → 网络数据：样本之间不是彼此独立
- 第 2 节 推荐系统 → 推荐系统：从稀疏评分到潜在兴趣
- 第 3 节 低秩矩阵估计问题 → 低秩估计：用少数方向解释大矩阵

实践任务：用一个缺失评分表说明为什么缺失不等于 0，并设计按时间保留的推荐测试。

## 第 12 章 深度学习与回归

能说明注意力、GP、贝叶斯优化与生成模型的输入、目标及不确定性。

- 第 1 节 Transformer 与回归 → Transformer 与回归：注意力是可学习的加权汇总
- 第 2 节 高斯过程回归与贝叶斯优化 → 高斯过程回归：对一整条函数表达不确定性；贝叶斯优化：实验很贵时下一次试哪里
- 第 3 节 生成模型 → 生成模型：从预测标签到学习数据分布

实践任务：不用训练大模型：手算一次注意力加权，给一个昂贵实验选择 GP+采集函数的理由。

## 第 13 章 过参数化、插值与现代泛化现象

能构造插值解，手算最小范数解，并有条件地解释双下降和隐式正则化。

- 第 1 节 从经典 bias–variance tradeoff 到插值解 → 插值：训练点全对以后还要问什么；偏差—方差分解：为什么更灵活不总更好
- 第 2 节 线性回归的插值解 → 线性插值的最小范数解

实践任务：固定数据种子和噪声，比较不同复杂度；若未出现双下降，也完整报告并解释可能原因。
