# 回归练习室：高维数据分析学习工作台

面向基础薄弱、每天学习 30 分钟的学生。纯静态 HTML/CSS/JavaScript，核心内容不依赖联网、API 或外部字体。手机浏览器访问 GitHub Pages 后即可使用。

## 从这里开始

打开 `index.html`，先做 8 题基础诊断。不要猜不会的题。

每天按「5 分钟回忆 → 15 分钟理解一个单元 → 10 分钟独立练习」进行。卡在一个单元时，可以拆成两天，不必按日历赶进度。

第一轮建议：

| 学习轮次 | 主题 | 能做到什么才继续 |
| --- | --- | --- |
| 1 | 求和、均值 | 能展开 Σ，用三个数算均值 |
| 2 | 散布、方差 | 知道为什么平方，分清 SXX 与样本方差 |
| 3 | 期望、随机 | 区分一次观测和重复抽样平均 |
| 4 | 协方差 | 展开线性组合方差，知道负号也要平方 |
| 5 | 矩阵 | 看懂一行样本、一列特征，算一次乘法 |
| 6 | 导数 | 用最小误差的例子理解一阶条件 |
| 7 | R 代码 | 逐行解释输入、运算、输出 |
| 之后 | 按大纲进入第 1—14 章 | 每节先讲懂，再做计算和迁移题 |

每轮先处理到期题；如果基础诊断已通过，可以直接打开课程单元，再用独立练习检查。这个安排是建议，不是每日必须完成的打卡。

## 已包含

- 对照教学大纲 14 章、66 小节，拆成 77 个课程与先修学习单元（含 11 个先修补课单元），另有 8 个 R 入门单元，全站共 85 个单元。
- 课程与先修单元含 231 道练习，R 入门另有 24 道；另设 8 道基础初筛题、每章练习与全课程 28 题查漏。
- 符号翻译、生活例子、分步例题、独立练习、自己的语言复述。
- 14 个互动实验：原有 均值散布、OLS、重复抽样、矩阵乘法、t 检验、预测区间、共线性、拟合复杂度、R 代码追踪，以及正则化收缩、PCA 投影、分类阈值、注意力和 LoRA 参数预算。
- 前三讲 A/B 两套 60 分钟自编模拟测验（保留原范围，不冒充全学期期中卷）：选择 16 分、判断 10 分、计算与推理 74 分。86 分自动判分，14 分证明题按评分要点自评。
- 错题、间隔复习、笔记、测验续答、历史记录、JSON 备份和恢复。
- 29 个补充资源入口，每个都写明「什么时候看、只做什么、怎样判断学会」。

## 学习记录如何计算

每个单元最近的答题结果中，至少两道独立答对，且含迁移题，才标为「练习通过」。打开提示的作答计为辅助练习，不计独立通过。看过页面只是「正在学习」。

错题立即进入队列；答对后隔 1 天复习，通过间隔复习后隔 3 天再次出现。题库有限，题目会重复，所以状态只反映这组练习的表现，不等同于全面掌握。所有计分均可在本机修改，不是防作弊考试系统。

参考了 [IELTS-practice](https://github.com/sallowayma-git/IELTS-practice) 的练习—记录—复盘流程，以及 [原数理统计仓库](https://github.com/sjsj20060407-droid/SUFE-notes-calculus) 的课程组织。代码、题目与界面独立编写，没有复制参考项目源码或题库。

外部补充资料在网页的「资源与备份」中逐项注明。网站不附带或公开上传教材全文、课堂 PDF、作业原件或用户学习记录。

## 手机使用与数据

建议在手机系统浏览器打开发布后的 Pages 地址，可通过浏览器菜单添加到主屏幕。网页不包含 Service Worker，添加到主屏幕不保证离线缓存。保存完整文件夹到电脑后，可直接打开 HTML；手机文件管理器可能限制本地脚本，请优先使用 HTTPS 网页。

学习数据只保存在当前浏览器的 localStorage，不自动跨设备同步。清除站点数据、换设备或隐私模式可能丢失进度。使用「资源与备份 → 导出 JSON」备份，再在另一个设备导入。导入会替换当前记录，操作前会提醒。

代码追踪是固定示例的教学演示，不是在线 R 解释器。工作台不调用聊天模型，也不自动判断自由文字证明是否正确。证明题总分会明确标注含自评。

## 维护

- `index.html`：入口。
- `styles.css`：桌面和手机样式。
- `data.js`：课程、练习、诊断、资源，静态 JSON 数据。
- `app.js`：导航、练习判分、互动实验、测验、备份。

新增 `大纲覆盖对照.md` 和 `公开资源导学.md`，可逐项核查范围与阅读任务。`全课程小实验.ipynb` / `.py` 含每章一个 NumPy 实验，已在本机执行核对。

`examples/linear-regression-assignment/` 收录配套的线性回归作业复现实例，含代码、教学数据与参考输出。数据来源和使用限制见该目录的 README。

核心页面不需要构建步骤。新增课程时同步维护题目 ID、先修关系、当前课程总数和对应测试范围。

为支持具备 WebMCP 的浏览器，提供能力检测后的进度读取、课程导航工具。不具备该接口时不影响普通使用；已测试模拟接口的注册及读回，没有宣称在原生 WebMCP 浏览器验证。


## 理解与应试怎么同时推进

学习时完成一个可观察任务：解释、手算、改参数或复现。每周用章节查漏题做一次闭卷回忆；检查错误属于公式、条件、计算还是解释。正式考试前，以教师公布范围为准选章节，不能把网页浏览率当作考试准备程度。公开资料按知识点关联，不要求一次学完所有外部教材。


## 从未学过 R：先看这里
